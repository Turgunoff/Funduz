- [ ] Backend API (auth, projects, pledges, users)
- [ ] DB schema и миграции
- [ ] UI создания и просмотра проекта
- [ ] Интеграция Payme (escrow flow)
- [ ] Интеграция Click
- [ ] Профиль бэкера
- [ ] Admin moderation panel
- [ ] Логика All-or-Nothing
- [ ] Refund flow (manual)
- [ ] Telegram bot (notifications)

### KPI
- Готовы 5–10 seed-проектов
- 3 платёжные системы протестированы
- 0 critical bugs

## Стратегические принципы

1. **Качество > Скорость** — один мошеннический проект может уничтожить всю репутацию
2. **Доверие — основная валюта** — каждый refund должен быть вовремя
3. **Локальный фокус** — не глобальный, а Узбекистан-first
4. **Mobile-first** — каждая новая функция сначала тестируется на мобильном
5. **Telegram-native** — аудитория там, и мы должны быть там
