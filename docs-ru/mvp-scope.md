# Объём MVP (Scope)

> Версия MVP: **v1.0**
> Цель: public launch в июле–августе 2026

---

## Must-have (v1.0)

Без этого запуск не состоится.

### Auth и пользователи
- [ ] Регистрация по номеру телефона (SMS OTP)
- [ ] Регистрация по email/паролю (альтернатива)
- [ ] Профиль пользователя (аватар, био, соцсети)
- [ ] Login / Logout / Восстановление пароля
- [ ] Login через Telegram (низкий приоритет)

### Проекты
- [ ] Wizard создания проекта (5–7 шагов)
  - Основная информация (заголовок, краткое описание, категория)
  - История (rich text editor)
  - Целевая сумма и продолжительность (30/45/60 дней)
  - Уровни наград (3–7 tier)
  - Медиа (изображения, видео URL)
  - Информация об авторе проекта
- [ ] Страница просмотра проекта (mobile + desktop)
- [ ] Поиск и фильтрация проектов (категория, статус, популярность)
- [ ] Обновления проекта (Updates) — посты автора

### Платежи и backing
- [ ] Создание pledge (выбор награды)
- [ ] Интеграция Payme (escrow)
- [ ] Интеграция Click (escrow)
- [ ] Логика All-or-Nothing
  - Цель достигнута: средства автору проекта
  - Не достигнута: автоматический refund
- [ ] Список проектов бэкера (My Pledges)

### Admin
- [ ] Модерация проектов (approve/reject)
- [ ] Управление пользователями
- [ ] Список платёжных транзакций
- [ ] Кнопка manual refund
- [ ] Основная статистика (общий GMV, активные проекты)

### Notification
- [ ] Email notification (transactional)
- [ ] Telegram bot (основные events: pledge, funded, refund)
- [ ] In-app notification

### Страницы
- [ ] Главная (hero + featured + trending) ✅ частично есть
- [ ] Explore (список проектов) ✅ частично есть
- [ ] Страница проекта
- [ ] Профиль пользователя
- [ ] FAQ / Помощь
- [ ] Пользовательское соглашение
- [ ] Политика конфиденциальности
- [ ] Контакты

### Языки
- [ ] Узбекский (основной) ✅ есть
- [ ] Русский ✅ есть
- [ ] Английский (в будущем)

---

## Nice-to-have (v1.1+)

Добавляется после запуска.

- Комментарии и Q&A
- Featured listing (paid)
- Premium analytics (для авторов проектов)
- A/B testing
- Push notifications (web)
- PWA (offline support)
- Расширенная аналитика в dashboard автора
- Списки продаж (best sellers, trending)
- Backer leaderboard
- Реферальная программа
- Paypal / международные карты (для зарубежных бэкеров)
- Crypto-платежи (USDT) — если есть регуляторное разрешение

---

## Out of scope (v1.0–v2.0)

Эти функции **не входят** в Funduz.

- ❌ Equity crowdfunding (конкуренция с Imkon VC)
- ❌ Donation / благотворительность (конкуренция с MFond.uz)
- ❌ ICO / token sale
- ❌ P2P lending
- ❌ Marketplace (e-commerce)
- ❌ Subscription crowdfunding (модель Patreon)
- ❌ Расширенный video streaming
- ❌ Native mobile app (после 12 месяцев)
- ❌ Международный launch (после 24 месяцев)
