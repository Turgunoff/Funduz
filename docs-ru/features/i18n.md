## Рекомендуемая структура файлов

Сейчас messages в одном файле `i18n.ts`, но до запуска MVP перенести в:

```
src/locales/
├── uz/
│   ├── common.json
│   ├── home.json
│   ├── project.json
│   ├── auth.json
│   └── errors.json
├── ru/
│   └── ...
└── en/
    └── ...
```

Затем `src/i18n.ts` будет dynamic import их.

## Стандарт ключей перевода

### Naming convention
- `kebab-case` или `camelCase` — выбрать одно и придерживаться
- Namespacing по модулям: `home.hero.title`, `project.create.step1.title`
- Чёткие, но не длинные

### Пример
```json
{
  "home": {
    "hero": {
      "title": "Воплотите свою идею в жизнь",
      "subtitle": "Первый reward-based краудфандинг в Узбекистане",
      "cta": "Начать проект"
    }
  }
}
```

### Pluralization
```json
{
  "backers": "Никто не поддержал | {n} человек поддержал | {n} человека поддержали | {n} человек поддержали"
}
```

{% raw %}
```vue
{{ t('backers', count) }}
```
{% endraw %}

### Interpolation
```json
{
  "raised": "Собрано {amount} сум"
}
```

{% raw %}
```vue
{{ t('raised', { amount: formatMoney(value) }) }}
```
{% endraw %}

## Форматы даты, времени и чисел

Используются `Intl.NumberFormat` и `Intl.DateTimeFormat`:

```typescript
// Деньги
new Intl.NumberFormat('ru-RU', { style: 'currency', currency: 'UZS', maximumFractionDigits: 0 }).format(amount)
// → "500 000 UZS"

// Дата
new Intl.DateTimeFormat('ru-RU', { dateStyle: 'medium' }).format(new Date())
// → "13 апр. 2026 г."
```

## Переключение языка

В `AppHeader.vue` есть language switcher (mobile + desktop).

```typescript
const { locale } = useI18n()
locale.value = 'ru' // изменение

// сохранение в localStorage:
localStorage.setItem('funduz:locale', locale.value)
```

## Добавление нового языка

1. Создать папку `src/locales/<код>/`
2. Перевести все JSON ключи (начать с uz)
3. Добавить `<код>` в `src/i18n.ts`
4. Добавить в language switcher `AppHeader`
5. Тест: открыть каждую страницу на новом языке

## Поддержание качества перевода

- **Dual review:** узбекский и русский переводы должен проверять носитель языка
- **Никогда не доверяйте Google Translate** — особенно для текстов о деньгах, refund, юридических
- **Консистентность:** одна и та же вещь везде называется одинаково (например: "проект" vs "кампания")
- **Глоссарий:** `docs/features/i18n-glossary.md` (в будущем) — словарь основных терминов
