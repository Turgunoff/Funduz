## Детализация расходов

### Разработка MVP ($15k–$25k)
**Варианты:**
- **In-house** (Eldor сам + 1 помощник): $0 зарплаты, 4–5 месяцев, но есть opportunity cost
- **Фрилансер (локальный)**: ~$15k–$20k, 3–4 месяца
- **Аутсорсинг (агентство)**: ~$25k+, 3 месяца

**Состав:**
- Frontend (Vue 3 — уже есть) — ~30%
- Backend API (NestJS или Go) — ~30%
- Admin panel — ~15%
- Платёжная интеграция (Payme, Click) — ~15%
- DevOps и deploy — ~10%

### Дизайн ($3k–$5k)
- Логотип и brand identity: $500–$1,000
- UI kit и design system: $1,500–$2,500
- Mobile + desktop экраны (15–20 шт.): $1,000–$1,500

### Маркетинг 1 год ($5k–$10k)
- Telegram-канал и контент: $1,000
- Influencer marketing (3–5 шт.): $1,500–$3,000
- Публикации в Daryo.uz / Pivot.uz / Spot.uz: $1,000–$2,000
- IT Park / стартап-события: $500–$1,500
- Targeted ads (Facebook, Instagram, Telegram Ads): $1,000–$2,500

### Инфраструктура (годовая $1.5k–$3k)
- Cloud сервер (VPS или AWS/GCP): $50–$150/мес
- Database hosting: $30–$80/мес
- CDN и static storage: $20–$50/мес
- Monitoring (Sentry, Grafana): $0–$50/мес
- Domain + SSL: $50/год

### Юридическое ($2k–$4k)
- Регистрация ООО: ~$200
- Резидентство IT Park (если заявка одобрена): бесплатно
- Юрист (договор с пользователем, privacy policy, оферта): $1,000–$2,000
- Договор с платёжным оператором: $0 (Payme/Click — бесплатно)
- Бухгалтер (полставки): $100–$200/мес
