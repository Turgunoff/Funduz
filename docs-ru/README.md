# Funduz — Документация

**Funduz** — reward-based краудфандинговая платформа для Узбекистана. В этой папке собрана бизнес-, техническая и операционная документация проекта.

> Язык: русский (технические термины — на английском)
> Статус проекта: разработка MVP
> Стек: Vue 3 + TypeScript + Pinia + Vue Router + Vue I18n + Tailwind CSS

> 🇺🇿 Узбекская версия: [../docs/](../docs/README.md)
