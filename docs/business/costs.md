## Xarajat tafsilotlari

### MVP dasturlash ($15k–$25k)
**Variantlar:**
- **In-house** (Eldor o'zi + 1 yordamchi): $0 mehnat haqi, 4–5 oy vaqt, lekin opportunity cost bor
- **Freelancer (mahalliy)**: ~$15k–$20k, 3–4 oy
- **Outsourcing (agentlik)**: ~$25k+, 3 oy

**Tarkib:**
- Frontend (Vue 3 — hozir mavjud) — ~30%
- Backend API (NestJS yoki Go) — ~30%
- Admin panel — ~15%
- To'lov integratsiyasi (Payme, Click) — ~15%
- DevOps va deploy — ~10%

### Dizayn ($3k–$5k)
- Logo va brand identity: $500–$1,000
- UI kit va design system: $1,500–$2,500
- Mobile + desktop ekranlar (15–20 ta): $1,000–$1,500

### Marketing 1-yil ($5k–$10k)
- Telegram kanal va kontent: $1,000
- Influencer marketing (3–5 ta): $1,500–$3,000
- Daryo.uz / Pivot.uz / Spot.uz publikatsiyalari: $1,000–$2,000
- IT Park / startup eventlar: $500–$1,500
- Targeted ads (Facebook, Instagram, Telegram Ads): $1,000–$2,500

### Infratuzilma (yillik $1.5k–$3k)
- Cloud server (VPS yoki AWS/GCP): $50–$150/oy
- Database hosting: $30–$80/oy
- CDN va static storage: $20–$50/oy
- Monitoring (Sentry, Grafana): $0–$50/oy
- Domain + SSL: $50/yil

### Yuridik ($2k–$4k)
- MChJ ro'yxatga olish: ~$200
- IT Park rezidentligi (agar ariza qabul qilinsa): bepul
- Yurist (foydalanuvchi shartnomasi, privacy policy, oferta): $1,000–$2,000
- To'lov operatori bilan shartnoma: $0 (Payme/Click bilan tekin)
- Buxgalter (yarim stavka): $100–$200/oy

Agar Funduz IT Park rezidenti bo'lsa:
- **Soliq imtiyozlari:** korporativ daromad solig'i 0%, IT mutaxassislariga IIDS 7.5% (umumiy 12% o'rniga)
- **Eksport bojxonasi imtiyozlari**
- **$50M "Digital Startups" dasturi** ga ariza topshirish huquqi
- **Soliq hisoboti soddalashtirilgan**

> Tavsiya: MVP launch'idan oldin IT Park'ga ariza topshirish.
