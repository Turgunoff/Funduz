## Tarjima kalitlari standarti

### Naming convention
- `kebab-case` yoki `camelCase` — bitta tanlang va saqlang
- Module bo'yicha namespacing: `home.hero.title`, `project.create.step1.title`
- Aniq, lekin uzun bo'lmasin

### Misol
```json
{
  "home": {
    "hero": {
      "title": "G'oyangizni hayotga tatbiq eting",
      "subtitle": "O'zbekistondagi birinchi reward-based kraudfanding",
      "cta": "Loyiha boshlash"
    }
  }
}
```

### Pluralization
```json
{
  "backers": "Hech kim qo'llab-quvvatlamagan | {n} kishi qo'llab-quvvatladi | {n} kishi qo'llab-quvvatladi"
}
```

{% raw %}
```vue
{{ t('backers', count) }}
```
{% endraw %}

### Interpolation
```json
{
  "raised": "{amount} so'm yig'ildi"
}
```

{% raw %}
```vue
{{ t('raised', { amount: formatMoney(value) }) }}
```
{% endraw %}

## Sana, vaqt va son formatlari

`Intl.NumberFormat` va `Intl.DateTimeFormat` ishlatiladi:

```typescript
// Pul
new Intl.NumberFormat('uz-UZ', { style: 'currency', currency: 'UZS', maximumFractionDigits: 0 }).format(amount)
// → "500 000 UZS"

// Sana
new Intl.DateTimeFormat('uz-UZ', { dateStyle: 'medium' }).format(new Date())
// → "13 apr 2026"
```

## Til almashtirish

`AppHeader.vue` da til switcher mavjud (mobile + desktop).

```typescript
const { locale } = useI18n()
locale.value = 'ru' // o'zgartirish

// localStorage'ga saqlash:
localStorage.setItem('funduz:locale', locale.value)
```

## Yangi til qo'shish (kelajakda)

1. `src/locales/<kod>/` papkasi yarating
2. Hamma JSON kalitlarini tarjima qiling (uz'dan boshlang)
3. `src/i18n.ts` ga `<kod>` qo'shing
4. `AppHeader` til switcher'iga qo'shing
5. Test: har bir sahifani yangi tilda ochib chiqing
