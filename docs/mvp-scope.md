# MVP Doirasi (Scope)

> MVP versiyasi: **v1.0**
> Maqsad: 2026 iyul–avgust public launch

---

## Must-have (v1.0)

Bularsiz launch qilinmaydi.

### Auth va foydalanuvchilar
- [ ] Telefon raqami orqali ro'yxatdan o'tish (SMS OTP)
- [ ] Email/parol bilan ro'yxatdan o'tish (alternativ)
- [ ] Foydalanuvchi profili (avatar, bio, ijtimoiy tarmoqlar)
- [ ] Login / Logout / Parolni tiklash
- [ ] Telegram bilan login (oxirgi prioritet)

### Loyihalar
- [ ] Loyiha yaratish wizard (5–7 qadam)
  - Asosiy ma'lumotlar (sarlavha, qisqa tavsif, kategoriya)
  - Hikoya (rich text editor)
  - Maqsad summa va davomiyligi (30/45/60 kun)
  - Reward darajalari (3–7 ta tier)
  - Media (rasmlar, video URL)
  - Loyiha egasi haqida ma'lumot
- [ ] Loyiha ko'rish sahifasi (mobile + desktop)
- [ ] Loyiha qidiruvi va filtrlash (kategoriya, status, populyarlik)
- [ ] Loyiha yangilanishlari (Updates) — egasi tomonidan post

### To'lov va backing
- [ ] Pledge yaratish (reward tanlash)
- [ ] Payme integratsiyasi (escrow)
- [ ] Click integratsiyasi (escrow)
- [ ] All-or-Nothing logikasi
  - Maqsadga yetilsa: fundlar loyiha egasiga
  - Yetilmasa: avtomatik refund
- [ ] Backer'larning loyihalari ro'yxati (My Pledges)

### Admin
- [ ] Loyihalarni moderatsiya qilish (approve/reject)
- [ ] Foydalanuvchilarni boshqarish
- [ ] To'lov tranzaksiyalari ro'yxati
- [ ] Manual refund tugmasi
- [ ] Asosiy statistika (jami GMV, faol loyihalar)

### Notification
- [ ] Email notification (transactional)
- [ ] Telegram bot (asosiy events: pledge, funded, refund)
- [ ] In-app notification

### Sahifalar
- [ ] Asosiy sahifa (hero + featured + trending) ✅ qisman bor
- [ ] Explore (loyihalar ro'yxati) ✅ qisman bor
- [ ] Loyiha sahifasi
- [ ] Foydalanuvchi profili
- [ ] FAQ / Yordam
- [ ] Foydalanish shartnomasi
- [ ] Maxfiylik siyosati
- [ ] Kontakt

### Til
- [ ] O'zbek (asosiy) ✅ bor
- [ ] Rus ✅ bor
- [ ] Ingliz (kelajakda)

---

## Nice-to-have (v1.1+)

Launch'dan keyin qo'shiladi.

- Komentariyalar va Q&A
- Featured listing (paid)
- Premium analytics (loyiha egasi uchun)
- A/B testing
- Push notifications (web)
- PWA (offline support)
- Loyiha egasi dashboard'ida advanced analytics
- Sotuv ro'yxatlari (best sellers, trending)
- Backer leaderboard
- Referral dasturi
- Paypal / xalqaro karta to'lovi (xalqaro backerlar uchun)
- Crypto to'lov (USDT) — agar regulyativ ruxsat bo'lsa

---

## Out of scope (v1.0–v2.0)

Bu funksiyalar Funduz doirasiga **kirmaydi**.

- ❌ Equity crowdfunding (Imkon VC bilan raqobat)
- ❌ Donation / xayriya (MFond.uz bilan raqobat)
- ❌ ICO / token sale
- ❌ P2P lending
- ❌ Marketplace (e-commerce)
- ❌ Subscription crowdfunding (Patreon model)
- ❌ Advanced video streaming
- ❌ Native mobile app (12-oydan keyin)
- ❌ Xalqaro launch (24-oydan keyin)
