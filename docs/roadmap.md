# Yo'l Xaritasi (Roadmap)

> Loyiha boshlanishi: 2026 aprel
> MVP launch maqsadi: 2026 iyul/avgust

---

## Bosqich 1 — MVP yaratish (0–3 oy)

**Davr:** 2026 aprel – iyul

### Maqsadlar
- Asosiy funksionallik tayyor
- 5–10 ta "seed" loyiha topib, platformani test qilish
- Yopiq beta launch (faqat tanlangan foydalanuvchilar)

### Deliverables
- [x] Frontend skelet (Vue 3, router, i18n, AppHeader)
- [ ] Backend API (auth, projects, pledges, users)
- [ ] DB schema va migratsiyalar
- [ ] Loyiha yaratish va ko'rish UI
- [ ] Payme integratsiyasi (escrow flow)
- [ ] Click integratsiyasi
- [ ] Backer profili
- [ ] Admin moderation panel
- [ ] All-or-Nothing logikasi
- [ ] Refund flow (manual)
- [ ] Telegram bot (notifications)

### KPI
- 5–10 ta seed loyiha tayyor
- 3 ta to'lov tizimi sinovdan o'tgan
- 0 ta critical bug

## Strategik tamoyillar

1. **Sifat > Tezlik** — bitta firibgarlik loyiha butun obro'ni buzishi mumkin
2. **Ishonch — asosiy valyuta** — har bir refund vaqtida bo'lsin
3. **Mahalliy fokus** — global emas, O'zbekiston-first
4. **Mobile-first** — har qanday yangi funksiya birinchi mobil'da test qilinadi
5. **Telegram-native** — auditoriya u yerda, biz ham u yerda bo'lishimiz kerak
