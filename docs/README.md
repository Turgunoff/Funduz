# Funduz — Hujjatlar

**Funduz** — O'zbekiston uchun reward-based kraudfanding platformasi. Bu papka loyihaning biznes, texnik va operatsion hujjatlarini saqlaydi.

> Til: o'zbek (texnik atamalar — inglizcha)
> Loyiha holati: MVP ishlab chiqish bosqichi
> Stack: Vue 3 + TypeScript + Pinia + Vue Router + Vue I18n + Tailwind CSS
